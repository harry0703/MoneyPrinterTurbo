# Local Voice Workspace

Use this folder for private local voice-cloning experiments.

This is an unsupported, manually operated experiment and is not connected to
MoneyPrinterTurbo campaigns. Use only voices with explicit permission, verify
the selected tool/model license before downloading it, and delete local source
audio and profiles when they are no longer needed.

- `reference/`: consented reference voice clips.
- `scripts/`: short narration scripts for smoke tests.
- `output/`: generated WAV/MP3 narration files.

The `.gitignore` in this folder intentionally ignores voice samples, generated audio, logs, model caches, and other local artifacts. Do not commit personal voice data or generated cloned-voice files.
