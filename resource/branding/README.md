# Logos des comptes

Un fichier par compte, utilisé pour le badge « FOLLOW » de fin de vidéo.

| Fichier | Compte |
|---|---|
| `why.png` | why.though101 |
| `waypoint.png` | waypoint.60 |
| `creature.png` | creature.feature60 |

Format attendu : **PNG carré**, 400x400 minimum (800x800 idéal). Le logo est
recadré en cercle avec un anneau blanc, comme un avatar Instagram — le sujet
doit donc rester dans le cercle inscrit, pas dans les coins.

La couleur du bouton reprend automatiquement la couleur de surlignage des
sous-titres du compte (`subtitle_highlight_color` dans `content_plan.json`), et
la couleur du texte du bouton est choisie selon la luminosité de ce fond.

Chemins configurés dans `content_plan.json`, clé `accounts.<compte>.outro`.
