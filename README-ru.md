## System Requirements 📦

- Windows 10+, macOS 11+ или mainstream Linux
- Python 3.11+ (рекомендуется 3.11)
- GPU не обязателен, но полезен для локальной транскрипции, обработки видео и batch

| Item | Minimum | Recommended | Optimal |
| ---- | ------- | ----------- | ------- |
| CPU  | 4 cores | 6–8 cores   | 8+ cores |
| RAM  | 4 GB    | 8 GB        | 16+ GB |
| GPU  | Not required | 4+ GB VRAM | 8+ GB VRAM |

- Для cloud LLM / TTS / online materials важнее CPU и RAM
- Для `faster-whisper`, batch и тяжёлого local processing GPU заметно ускоряет работу

## Installation & Deployment 📥

### Prerequisites

- Python 3.11+
- На Windows избегайте путей с non-ASCII, спецсимволами и пробелами

#### ① Clone

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Initial Setup

При первом запуске создаётся `config.toml` из `config.example.toml`. API keys для cloud LLM / footage / AI video добавьте в WebUI basic settings.

### Docker Deployment 🐳

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> По умолчанию `docker-compose.release.yml` тянет `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Локальная сборка: `docker compose up`.
> Перед первым стартом скопируйте `config.example.toml` → `config.toml`.

- WebUI: http://127.0.0.1:8501
- API docs: http://127.0.0.1:8080/docs или http://127.0.0.1:8080/redoc

> Same-origin browser access по умолчанию. `CORS_ALLOWED_ORIGINS` нужен только для отдельного frontend с другого origin. На curl / Postman / n8n CORS не влияет.

### Manual Deployment 📦

#### ① Virtual environment ([uv](https://docs.astral.sh/uv/))

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Или legacy `venv + pip`:

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- Primary manifest: `pyproject.toml`
- Рекомендуется `uv sync --frozen` (`uv.lock`)
- `requirements.txt` — для legacy pip

#### ② WebUI 🌐

###### Windows

```powershell
.\webui.bat
```

`webui.bat` предпочитает `.venv` / bundled Python; fallback — `uv run streamlit`.
LAN-доступ: `set MPT_WEBUI_HOST=0.0.0.0` перед запуском.

###### macOS / Linux

```shell
sh webui.sh
```

LAN:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

#### ③ API Service 🚀

```shell
uv run python main.py
# или, если venv уже активирован:
python main.py
```

#### ④ Pure CLI Mode ⌨️

```shell
uv run python cli.py --video-subject "How AI is changing everyday life"
```

Порядок для subtitle/voiceover: **явная CLI-опция > `[ui]` в `config.toml` > default**. Остальные generation settings из WebUI не наследуются. Если в WebUI загружен audio — передайте `--custom-audio-file`.

```shell
uv run python cli.py --help
```

Пакетно — UTF-8 JSON array / JSONL (до 100 задач, 1 MiB):

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

## Voiceover, Subtitles, and Background Music 🎙️

### Voice Synthesis

**Azure TTS V1** в WebUI = **Edge TTS** (бесплатно, без API key). Также: Azure TTS V2, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, self-hosted Chatterbox / Kokoro, Fish Audio, [ModelBest VoxCPM](https://platform.modelbest.cn/console/docs/api/audio), режим без голоса.

Список Edge TTS voices: [docs/voice-list.txt](./docs/voice-list.txt).

### Subtitle Generation

- **edge** (default): timestamps из TTS, быстро, без GPU
- **whisper**: локальный `faster-whisper` для более точной таймлинии

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

По умолчанию Whisper качает ~3 GB `large-v3`; `large-v3-turbo` ≈ 1.6 GB. При ошибке скачивания скачайте модель с [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3) в `.\MoneyPrinterTurbo\models\whisper-large-v3`.

### Background Music / Fonts

- Музыка: `resource/songs` (дефолтные треки с YouTube — при copyright-проблемах удалите)
- Шрифты субтитров: `resource/fonts` (можно добавить свои)

## Common Questions 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Обычно ffmpeg скачивается автоматически. Если нет — скачайте с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) и задайте:

```toml
[app]
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

```shell
ulimit -n
ulimit -n 10240
```

</details>

<details>
<summary>Whisper model download failed</summary>

Скачайте модель вручную с Hugging Face — см. раздел Subtitle Generation выше.

</details>
