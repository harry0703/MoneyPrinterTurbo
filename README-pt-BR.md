# MoneyPrinterTurbo 💸

### Gerador completo de vídeos curtos com IA

Forneça um <b>tema</b> ou uma <b>palavra-chave</b> para o vídeo, e o MoneyPrinterTurbo gerará o roteiro, selecionará os materiais visuais, criará legendas e música de fundo e produzirá um vídeo curto em alta definição.

## Recursos 🎯

### Fluxos de criação

- [x] Use fluxos com **AI Agent, WebUI, API ou CLI** para criação rápida ou produção automatizada
- [x] Parta de um tema e gere automaticamente roteiro, narração, materiais visuais, legendas, música e edição, mantendo controle sobre cada etapa
- [x] Gere várias versões de saída em lote, consulte o histórico de tarefas e importe ou exporte configurações de geração e chaves de API

### Roteiros e provedores de modelos

- [x] Gere ou reescreva **roteiros de vídeo multilíngues** com IA ou forneça um roteiro personalizado completo
- [x] Use provedores como [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-f6b0a640d35c41deb03b247242a1058c&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/) e [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Conecte-se por [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [Ollama](https://ollama.com/), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/) e outros gateways compatíveis ou runtimes locais

### Materiais de vídeo e imagem

- [x] Envie suas próprias **imagens e vídeos locais** ou obtenha materiais em HD do [Pexels (gratuito)](https://www.pexels.com/api/), [Pixabay (gratuito)](https://pixabay.com/api/docs/) e [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Gere materiais de origem em `768P` ou `2K` com [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT), com clipes de 4 a 15 segundos em `9:16`, `16:9` ou `1:1`
- [x] Crie vários clipes de vídeo com IA usando o [Shengsuan Cloud AI Video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK) e combine-os com o fluxo de narração, legendas e edição do projeto
- [x] Use a integração nativa do [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) para gerar visuais coerentes a partir de segmentos individuais do roteiro
- [x] Transforme palavras-chave do roteiro em vídeos originais com [WaveSpeed AI](https://wavespeed.ai)
- [x] Acesse Seedance, Wan e outros modelos de texto para vídeo por meio da [OFox](https://ofox.ai) com uma única chave de API
- [x] Conecte serviços de [texto para imagem compatíveis com OpenAI](https://platform.openai.com/docs/guides/image-generation) ou gateways personalizados de imagem e transforme as imagens geradas em clipes animados
- [x] Ajuste a duração dos clipes, o enquadramento e a ordem dos materiais para diferentes proporções e estilos narrativos

### Narração, legendas e música de fundo

- [x] Escolha narração automática, áudio enviado ou ausência de narração, com amostras de voz e pré-visualização completa
- [x] Use **Edge TTS (gratuito e sem necessidade de chave de API)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Fish Audio e outros serviços de voz
- [x] Gere legendas e configure fonte, posição, cor, tamanho, contorno e estilo de fundo
- [x] Use música de fundo aleatória, local ou gerada por IA, com controle independente de volume

### Saída e publicação

- [x] Exporte vídeos verticais `9:16 (1080×1920)`, horizontais `16:9 (1920×1080)` ou quadrados `1:1 (1080×1080)`
- [x] Publique os vídeos concluídos diretamente no **TikTok, Instagram e YouTube Shorts**

## Requisitos do sistema 📦

- Plataformas recomendadas: Windows 10+, macOS 11+ ou uma distribuição Linux convencional
- A implantação local requer Python 3.11 ou posterior; Python 3.11 é recomendado
- GPU não é obrigatória, mas é recomendada para transcrição local mais rápida, processamento de vídeo mais veloz ou geração em lote mais fluida

| Item | Mínimo | Recomendado | Ideal |
| ---- | ------ | ----------- | ----- |
| CPU  | 4 núcleos | 6 a 8 núcleos | 8+ núcleos |
| RAM  | 4 GB | 8 GB | 16+ GB |
| GPU  | Não obrigatória | 4+ GB de VRAM | 8+ GB de VRAM |

- Se você utiliza principalmente LLMs em nuvem, TTS em nuvem e fontes de materiais on-line, CPU e RAM são mais importantes que a GPU
- Se você usa `faster-whisper`, geração em lote ou processamento local mais pesado, uma GPU aumentará perceptivelmente a taxa de processamento

## Instalação e implantação 📥

### Pré-requisitos

- A implantação local requer Python 3.11 ou posterior
- No Windows, evite caminhos do projeto contendo caracteres não ASCII, caracteres especiais ou espaços

#### ① Clonar o projeto

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Concluir a configuração inicial

Na primeira inicialização, o projeto cria `config.toml` a partir de `config.example.toml`, portanto você não precisa criar o arquivo manualmente. Antes de usar LLMs em nuvem, materiais on-line ou serviços de vídeo com IA, adicione as chaves de API correspondentes nas configurações básicas da WebUI.

### Implantação com Docker 🐳

#### ① Iniciar o contêiner Docker

Se o Docker não estiver instalado, [baixe e instale o Docker Desktop](https://www.docker.com/products/docker-desktop/) primeiro.
Se estiver usando Windows, consulte a documentação da Microsoft:

1. [Instalar o WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
2. [Usar contêineres Docker com WSL](https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> A configuração padrão recomendada é `docker-compose.release.yml`, que baixa a imagem pré-compilada do GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Se você precisar compilar a imagem localmente, ainda poderá executar `docker compose up`.
> Antes da primeira inicialização, copie `config.example.toml` para `config.toml` para que o arquivo possa ser montado nos contêineres.

#### ② Acessar a WebUI

Abra o navegador e acesse http://127.0.0.1:8501

#### ③ Acessar a documentação da API

Abra o navegador e acesse http://127.0.0.1:8080/docs ou http://127.0.0.1:8080/redoc

> A API permite acesso do navegador a partir da mesma origem por padrão. Defina a variável de ambiente `CORS_ALLOWED_ORIGINS` somente quando um frontend separado precisar chamar a API diretamente a partir de outra origem, por exemplo `http://localhost:3000,https://frontend.example.com`. CORS não afeta curl, Postman, n8n ou outros clientes executados no lado do servidor.

### Implantação manual 📦

#### ① Criar um ambiente virtual Python

Use [uv](https://docs.astral.sh/uv/) para gerenciar o ambiente Python e as dependências. O projeto oferece suporte a Python 3.11 ou posterior; o exemplo abaixo usa Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Se ainda não estiver usando `uv`, você pode usar `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Observações:

- `pyproject.toml` agora é o manifesto principal de dependências.
- `uv.lock` fixa o ambiente resolvido, portanto `uv sync --frozen` é recomendado por padrão.
- `requirements.txt` é mantido apenas para instalações legadas baseadas em `pip`.

#### ② Iniciar a WebUI 🌐

Os comandos a seguir devem ser executados no `diretório raiz` do projeto MoneyPrinterTurbo.

###### Windows

```powershell
.\webui.bat
```

Também é possível executar `webui.bat` no CMD.
`webui.bat` prioriza o `.venv` do projeto ou o Python incluído no pacote portátil. Se não encontrar um Python do projeto, mas `uv` estiver instalado, ele usa automaticamente `uv run streamlit`.
Para permitir que outros dispositivos da rede local acessem a WebUI, execute `set MPT_WEBUI_HOST=0.0.0.0` antes de executar `webui.bat`.

###### macOS ou Linux

```shell
sh webui.sh
```

O script usa automaticamente o ambiente virtual do projeto ou `uv` e seleciona uma porta local disponível. Para permitir acesso por outros dispositivos da rede local, execute:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Após a inicialização, o navegador será aberto automaticamente.

#### ③ Iniciar o serviço de API 🚀

```shell
uv run python main.py
```

Se você já tiver ativado o ambiente virtual manualmente, também poderá executar:

```shell
python main.py
```

#### ④ Modo CLI puro (sem navegador) ⌨️

Se você não puder usar navegador ou encaminhamento de portas, gere vídeos diretamente pela linha de comando. O comando completo mais simples é:

```shell
uv run python cli.py --video-subject "How AI is changing everyday life"
```

As opções de estilo de legenda e narração são resolvidas nesta ordem: **opção explícita da CLI > valor `[ui]` salvo em `config.toml` > valor padrão interno**. Outras configurações de geração, como música de fundo, quantidade de vídeos e quantidade de parágrafos, não são herdadas da WebUI. Se a WebUI estiver configurada para usar áudio enviado, informe `--custom-audio-file` explicitamente, pois o caminho enviado não é persistido.

Para consultar a referência completa de comandos, descrições dos parâmetros e instruções de uso, execute:

```shell
uv run python cli.py --help
```

Para executar várias tarefas sequencialmente, informe um array JSON UTF-8 ou um manifesto JSONL. As opções da CLI atuam como valores padrão, e cada objeto sobrescreve campos de `VideoParams`:

```json
[
  { "video_subject": "How solar panels work" },
  { "video_subject": "How wind turbines work", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

O manifesto é resolvido a partir do diretório de trabalho atual. Valores relativos de `custom_audio_file` e `video_materials[].url` dentro dele são resolvidos a partir do diretório do manifesto; caminhos informados como padrões da CLI mantêm a semântica normal relativa ao diretório de trabalho atual. Um manifesto é limitado a 100 tarefas e 1 MiB. Todas as entradas são validadas antes do início da primeira tarefa. As tarefas continuam após uma falha individual de execução, e o comando imprime um resumo JSON ao final. O resumo contém `total`, `succeeded`, `failed` e `tasks`; cada entrada de tarefa contém `index`, `task_id`, `status`, `result`, `failed_stage` e `error`.

## Narração, legendas e música de fundo 🎙️

### Síntese de voz

O **Azure TTS V1** da WebUI é baseado no **Edge TTS** e pode ser usado gratuitamente sem chave de API. O MoneyPrinterTurbo também oferece suporte a **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **ElevenLabs TTS**, **Chatterbox TTS** auto-hospedado, **Fish Audio TTS** e modo sem voz.

Selecione um provedor e uma voz na WebUI e siga as instruções exibidas para as credenciais necessárias. Edge TTS não exige chave de API; [Azure TTS V2](https://portal.azure.com/) e outros provedores em nuvem exigem credenciais das respectivas plataformas. Consulte as vozes do Edge TTS disponíveis na [lista de vozes](./docs/voice-list.txt).

### Geração de legendas

Há dois modos de geração de legendas:

- **edge**: usa timestamps do TTS, é executado rapidamente sem GPU e é o modo padrão.
- **whisper**: usa a transcrição local do `faster-whisper` quando é necessária uma linha do tempo de legendas mais precisa. O modelo é baixado no primeiro uso.

Defina `subtitle_provider` em `config.toml` para alternar entre os modos. O Whisper usa por padrão o modelo `large-v3`, de aproximadamente 3 GB. Para usar o modelo `large-v3-turbo`, menor e mais rápido, com aproximadamente 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> No primeiro uso, o Whisper baixa automaticamente o modelo do Hugging Face. Se o download automático falhar, baixe manualmente `whisper-large-v3` no [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Após extrair o modelo, coloque o diretório inteiro em `.\MoneyPrinterTurbo\models`. O caminho final deverá ser `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

### Música de fundo

As músicas de fundo dos vídeos ficam no diretório `resource/songs` do projeto.

> O projeto atual inclui algumas músicas padrão provenientes de vídeos do YouTube. Se houver questões de direitos autorais, exclua-as.

### Fontes das legendas

As fontes usadas para renderizar legendas ficam no diretório `resource/fonts` do projeto. Você também pode adicionar suas próprias fontes.

## Perguntas frequentes 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normalmente, o ffmpeg é baixado e detectado automaticamente.
Entretanto, se o ambiente impedir downloads automáticos, o seguinte erro poderá ocorrer:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Nesse caso, baixe o FFmpeg em [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extraia-o e configure `ffmpeg_path` com o caminho real de instalação.

```toml
[app]
# Configure de acordo com o caminho real. Observe que os separadores de caminho do Windows são \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Esse problema é causado pelo limite do sistema para a quantidade de arquivos abertos. É possível resolvê-lo alterando esse limite.

Verifique o limite atual:

```shell
ulimit -n
```

Se estiver muito baixo, aumente-o, por exemplo:

```shell
ulimit -n 10240
```

</details>
