# MoneyPrinterTurbo — دليل التشغيل بالعربية

يصنع المشروع فيديو قصيرًا بالكامل تلقائيًا: تكتب موضوعًا، فيولّد النص والتعليق الصوتي واللقطات والترجمة النصية والموسيقى.

## التشغيل بـ Docker (الأسهل)

```bash
docker compose -f docker-compose.release.yml up
```

ثم افتح http://127.0.0.1:8501

## التشغيل المحلي

يتطلب Python 3.11 أو أحدث، و FFmpeg.

```bash
uv sync
sh webui.sh        # على ويندوز: webui.bat
```

## الإعداد

عند أول تشغيل يُنشأ `config.toml` من `config.example.toml`. أضف المفاتيح من الإعدادات الأساسية في الواجهة:

1. **نموذج لغوي** لكتابة النص (OpenAI أو Gemini أو DeepSeek أو غيرها) — `llm_provider` و `<provider>_api_key`.
2. **لقطات الفيديو**: مفتاح Pexels المجاني (`pexels_api_keys`) أو Pixabay.

## إنشاء فيديو بالعربية

1. اكتب الموضوع في الواجهة، واختر لغة النص **العربية**.
2. اختر صوتًا عربيًا من القائمة، مثل `ar-SA-HamedNeural` أو `ar-EG-SalmaNeural` أو `ar-AE-FatimaNeural`. القائمة الكاملة في `docs/voice-list.txt` (ابحث عن `ar-`).
3. اختر نسبة الفيديو (9:16 للهاتف، أو 16:9) واضغط **توليد**.
4. إن ظهرت الحروف العربية في الترجمة النصية مقطّعة أو مقلوبة، اختر خطًا يدعم العربية في إعدادات الترجمة.

ملاحظة: واجهة المشروع ليس فيها ملف ترجمة عربي (`webui/i18n/ar.json`) بعد، لكن توليد الفيديو بالعربية مدعوم عبر الأصوات أعلاه.
