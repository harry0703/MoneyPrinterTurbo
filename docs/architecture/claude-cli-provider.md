# Провайдер `claude_code` и пресет промпта по плейбуку

Две независимые вещи, сделанные одним заходом:

1. **`claude_code`** — LLM-провайдер, который генерирует текст через локальный
   `claude -p` вместо HTTP-API. Нужен, чтобы использовать интерактивную подписку
   Claude там, где нет API-ключа.
2. **`script_prompt_preset = "playbook"`** — системный промпт шага `script`,
   собранный из `docs/playbook/`, вместо общего апстримного.

Обе выключены по умолчанию: без ключей в конфиге пайплайн работает как раньше.

Дата разработки: 2026-08-12. Статус: первое приближение, дальше планируется
нормальная интеграция через API.

---

## Провайдер: где он живёт

```
app/models/llm_provider.py     запись в реестре (adapter="claude_code")
        ↓
app/services/llm.py            ветка адаптера в _generate_response
        ↓
app/services/claude_cli.py     единственное место, знающее про subprocess
```

Контракт наружу не меняется: `prompt -> str`, ошибка возвращается тем же
`"Error: ..."`, что и у HTTP-провайдеров. В `task.py` провайдер не протекает.

## Как устроен вызов

```bash
claude -p --output-format json \
       --model opus --effort medium \
       --system-prompt "<движок генерации текста>" \
       --tools "" --strict-mcp-config --disable-slash-commands
```

Промпт подаётся **в stdin**: системный промпт сценария может доходить до 8000
символов, в argv такому не место.

Принятые решения:

- **`--system-prompt` перетирает системный промпт CLI.** Дефолтный — про работу
  с кодом; он и мешает копирайтингу, и стоит лишних токенов (в замере 6.8k
  против 1.6k).
- **Инструменты выключены** (`--tools ""`, `--strict-mcp-config`,
  `--disable-slash-commands`): нужен один текстовый ход, а не агент.
- **Рабочий каталог — временный.** Иначе в запрос уезжают `CLAUDE.md`, хуки и
  git-состояние проекта.
- **Сессионные переменные окружения не наследуются** (`CLAUDECODE`,
  `CLAUDE_CODE_*`). Исключение — `CLAUDE_CODE_OAUTH_TOKEN`: это учётные данные.
  Иначе запуск изнутри сессии Claude Code ведёт себя как вложенный агент.
- **Ответ парсится из JSON**, а не из текста: нужны `is_error` и понятная
  диагностика при упоре в лимиты.
- Результат прогоняется через тот же `_normalize_text_response`, что и остальные
  провайдеры — включая схлопывание переводов строк.

## Конфиг

```toml
llm_provider = "claude_code"
claude_code_model_name = ""     # пусто → opus
claude_code_binary_path = ""    # пусто → claude из PATH
claude_code_effort = ""         # пусто → medium; low|medium|high|xhigh|max
claude_code_timeout = 300
```

API-ключ и Base URL не нужны и в WebUI не показываются: авторизует локальный
логин `claude`.

## Ограничения

- Вызов синхронный, ~3–5 с на шаг. На ролик их до четырёх (script, terms, gif,
  метаданные публикации), при `video_count > 1` — умножается.
- Упор в квоту подписки валит задачу с текстом ошибки CLI; отдельного backoff
  под лимиты нет.
- В Docker бинарник ставится (`ARG INSTALL_CLAUDE_CODE=1`), но учётные данные
  остаются на хосте: нужен `-v ~/.claude:/root/.claude`.
- `ANTHROPIC_API_KEY` в окружении переключит CLI на биллинг по API, то есть мимо
  подписки. Специально не вычищается.

## Пресет промпта по плейбуку

```
config: script_prompt_preset / script_preset_platform / script_preset_format
        ↓
app/services/script_prompt.py            приоры длительности, скелеты форматов
        ↓
app/services/data/script_prompt_playbook.md   шаблон правил
        ↓
llm.build_script_prompt()                + тема, язык, число абзацев
```

Что перенесено из плейбука:

| Источник | Что попало в промпт |
| --- | --- |
| `script.md` | структура тактов, правило удержания, запрет padding'а, запрет шаблона и парафраза |
| `hooks.md` | требования к первой строке, запрет приветствий и анонсов темы |
| `timing.md` | приор длительности по платформе → бюджет слов (2.5 слова/сек) |
| `formats.md` | скелет формата, если он задан |

Приоритет: `custom_system_prompt` из запроса > пресет > апстримный
`DEFAULT_SCRIPT_SYSTEM_PROMPT`. Неизвестный пресет, неизвестная платформа или
формат не роняют генерацию — только warning и откат к дефолту.

Верхняя граница бюджета слов сформулирована как жёсткий cap: на замере без неё
модель выдавала 119 слов при приоре 20–30 с (≈75 слов), с ней — 71.

### Чего пресет не делает

Из плейбука в один системный промпт не помещается и оставлено на потом:

- **Hook Generator + Hook Scorer** (`hooks.md`): несколько кандидатов на идею,
  выбор лучшего и сохранение `hook_type` в метаданных ролика — это отдельные
  шаги пайплайна и поля задачи, переживающие Memory/Redis.
- **Фактология** (`script.md`): цепочка `research → claim list → verification`
  с хранением источников рядом с роликом.
- **Метаданные публикации** (`publishing.md`): правила против спамных хештегов
  в `build_social_metadata_prompt` не трогались.
