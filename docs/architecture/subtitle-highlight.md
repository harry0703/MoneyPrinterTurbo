# Субтитры: капс и подсветка ключевого слова

Две независимые опции рендера субтитров. Обе выключены по умолчанию
(`subtitle_uppercase = false`, `subtitle_highlight_enabled = false`), поведение
пайплайна без них не меняется: старый путь через MoviePy `TextClip` не тронут.

Дата разработки: 2026-08-13. Ветка: `feat/subtitle-caps-highlight`.

---

## Зачем

Вертикальные ролики смотрят без звука и по диагонали. Капс повышает читаемость
мелкого текста на телефоне, а выделенное цветом ключевое слово даёт точку входа
в фразу — глаз цепляется за него раньше, чем мозг решает, читать ли остальное.

## Два режима: `subtitle_highlight_mode`

`keyword` (по умолчанию) — подсветка **смысловая**: одно ключевое слово на фразу,
выбранное детерминированной эвристикой, горит цветом всю длительность показа фразы.

`karaoke` — подсветка едет по словам. Пословных таймингов TTS не отдаёт (ни Gemini,
ни MiMo — есть только тайминги фраз из `sub_maker`), поэтому слот слова внутри фразы
считается по числу букв: `karaoke_word_windows()` делит окно фразы пропорционально
длине слов. Это приближение, и оно тем точнее, чем короче фраза — в паре с
`subtitle_max_chars` ошибка внутри фразы остаётся заметно меньше одного слова.

Цена: на фразу рендерится не один `ImageClip`, а по одному на слово.

## Эвристика выбора слова

`app/services/video.py::pick_highlight_word(phrase) -> str | None`:

1. токенизация по пробелам, краевая пунктуация отбрасывается (`^\W+|\W+$`);
2. приоритет №1 — первое слово с цифрой («заработай **1000** рублей»);
3. иначе самое длинное слово длиной ≥5 символов, не входящее в захардкоженный
   стоп-список русских предлогов, союзов, частиц и местоимений
   (`_HIGHLIGHT_STOPWORDS`, матчинг регистронезависимый);
4. ничего не подошло → `None`, фраза рендерится без подсветки.

Эвристика чистая и детерминированная: перегенерация того же ролика подсвечивает
те же слова. LLM не вызывается.

## Рендер

`TextClip` красит строку одним цветом, поэтому при включённой подсветке фраза
рисуется функцией `create_highlighted_text_clip` в RGBA-картинку через PIL и
отдаётся MoviePy как `ImageClip`:

- перенос строк — тот же `wrap_text`, тем же шрифтом и кеглем;
- слова рисуются по одному, X-смещение каждого слова считается от ширины
  префикса строки (`font.getlength`), а не накоплением ширин — межсловные
  интервалы совпадают с цельной строкой;
- обводка — PIL `stroke_width`/`stroke_fill` из `params.stroke_width` /
  `params.stroke_color`;
- ключевое слово — цветом `subtitle_highlight_color` (первое совпадение),
  остальные — `params.text_fore_color`;
- вертикальные метрики повторяют TextClip-путь (`interline`, `margin_y`,
  фиксированная высота в ветке без фона), позиция и размер блока субтитров
  не меняются;
- `ImageClip` подставляется во все три ветки `create_text_clip`: круглая
  плашка, прямоугольная плашка, без фона — совместимость с
  `subtitle_background_*` сохраняется.

Капс (`subtitle_uppercase`) применяется до `wrap_text` и до выбора ключевого
слова, поэтому перенос и матчинг считаются по поднятому регистру. Озвучка не
затрагивается — в TTS текст уходит в исходном регистре.

## Параметры

| Параметр `VideoParams` | Default | CLI |
|---|---|---|
| `subtitle_uppercase` | `false` | `--subtitle-uppercase/--no-subtitle-uppercase` |
| `subtitle_highlight_enabled` | `false` | `--subtitle-highlight/--no-subtitle-highlight` |
| `subtitle_highlight_color` | `#FFD700` | `--subtitle-highlight-color #RRGGBB` |
