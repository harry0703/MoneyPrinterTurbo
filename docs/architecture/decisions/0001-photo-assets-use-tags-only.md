# ADR 0001: у фото-ассетов только теги, без collection

- Статус: принято
- Дата: 2026-08-17

## Контекст

Группу изображений можно представить либо отдельным полем `collection`, либо
тегом, который используется как фильтр. Две параллельные оси создают неоднозначность
при ингесте, поиске и ручном редактировании.

## Решение

В библиотеке существует только `asset_tag` с весом. Отдельного поля, таблицы или
API `collection` нет. Имя папки при ингесте становится ручным тегом с весом 1.0.

## Последствия

- Любая группировка работает через те же `prefer`, `only`, `exclude` и `require`.
- Перенос каталога не требует синхронизации отдельной коллекции.
- Если понадобятся иерархии или права доступа, это будет новое решение, а не
  молчаливое добавление `collection`.
