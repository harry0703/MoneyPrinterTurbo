# 2D cartoon studio

Turn a written storyboard into a 2D cartoon video. Frames are generated by the
configured `openai_image` source, narration by the existing voice service, and
the final episode is assembled by the revision-aware `video_project` renderer.
Nothing here publishes videos or adds new Python dependencies.

## Requirements

- An OpenAI-compatible image endpoint configured in `config.toml`:

  ```toml
  [app]
  openai_image_base_url = "http://127.0.0.1:7861/v1"
  openai_image_model = "realvisxl-v5-lightning"
  ```

  See [local-image-server](local-image-server/README.md) to run one locally.
  The studio bypasses `openai_image_prompt_template`: it builds cartoon prompts
  itself, so a photographic template does not leak into the frames.
- FFmpeg/FFprobe on `PATH` for clip rendering and the final export.
- A voice name for narration. Without `--voice` the episode is a silent
  storyboard video that uses each scene's `duration`.

## Storyboard manifest

Save `cartoon.json` in the project directory:

```json
{
  "project_id": "paper-boat",
  "title": "The paper boat",
  "style": "flat-2d",
  "aspect": "9:16",
  "characters": [
    {"name": "Mia", "description": "a girl with a red scarf and short black hair"},
    {"name": "Pip", "description": "a small orange cat"}
  ],
  "scenes": [
    {
      "id": "opening",
      "visual": "Mia folds a paper boat at a kitchen table",
      "narration": "Mia had one sheet of paper left.",
      "duration": 4,
      "characters": ["Mia"]
    },
    {
      "id": "river",
      "visual": "the boat drifts down a rain-filled gutter",
      "narration": "The gutter became a river.",
      "duration": 5,
      "characters": ["Pip"]
    }
  ]
}
```

Styles: `flat-2d`, `anime`, `comic`, `storybook`. A custom style is an object:

```json
{"name": "ink", "prompt": "black ink on cream paper", "negative": "color"}
```

Each scene's prompt is the style, the descriptions of its own characters, the
visual, and the style's negative phrases. Listing a character in `characters`
keeps their design consistent across scenes. Scene IDs must stay stable when
you edit the manifest: they name the frames, audio and revision stages.

## Run

```sh
# Prompts only: no API calls, no paid image generation.
python -m app.services.cartoon_studio --project storage/cartoon/paper-boat storyboard

# Generate one PNG per scene into <project>/images.
python -m app.services.cartoon_studio --project storage/cartoon/paper-boat images

# Frames (if missing), narration, clips and the final episode.
python -m app.services.cartoon_studio --project storage/cartoon/paper-boat build \
  --voice en-US-AriaNeural

# Burn each scene's narration on screen and loop a local music track.
python -m app.services.cartoon_studio --project storage/cartoon/paper-boat build \
  --voice en-US-AriaNeural --subtitles --bgm resource/songs/output000.mp3 \
  --bgm-volume 0.12
```

`--manifest` points at a different file. `build` accepts `--voice-rate`,
`--subtitles`, `--subtitle-size` (default 56), `--bgm`, `--bgm-volume`
(default 0.15), `--retry` and `--stage-timeout`.

Subtitles are burned during the final export, after clips are scaled to the
chosen aspect, so they stay inside the frame. One line is shown per scene for
the length of its audio and it wraps to the screen width. The narration text is
what gets burned; it is not re-transcribed. Background music must be a local
standalone audio file and is looped to the episode length by the renderer.

Frames and narration are content-addressed by prompt/text and voice, so
rerunning a command reuses unchanged files and only regenerates what changed.
The export path is reported in the `status.export.path` field of the JSON
output.

## Articulated 2D animation

Add an `animation` section to `cartoon.json` (a character preset plus a
per-scene animation object) to render articulated characters instead of
camera motion over stills. Animation mode is opt-in and offline:

```sh
python -m app.services.cartoon_studio --project storage/cartoon/primer-episodio \
  build --mode animation --voice es-CO-SalomeNeural --subtitles
```

Projects without an `animation` section keep using the classic workflow, and
`--mode classic` forces it. See
[cartoon-studio-animation.md](cartoon-studio-animation.md) for the manifest
schema, built-in animations, lip sync, rendering settings and CLI commands.
