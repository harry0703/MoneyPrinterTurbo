# Тайминги и длительность

Длительность — **приор эксперимента, а не константа**. Всё ниже — стартовые значения,
которые обязаны быть вытеснены собственными account-level данными, как только наберётся
статистика.

## Стартовые приоры

```yaml
tiktok:
  fast:
    target: 20-30s
  story:
    target: 60-150s

instagram_reels:
  default:
    target: 45-60s

youtube_shorts:
  default:
    target: 20-40s
```

Диапазон YouTube — продуктовая гипотеза, внешними данными не подтверждён.

## Приор — не константа

Плохо:

```python
if platform == "instagram":
    duration = 52
```

Хорошо:

```python
prior = DurationPrior(
    platform="instagram",
    preferred_range=(45, 60),
    confidence="external_benchmark"
)
```

Во втором виде наши собственные данные потом переопределяют приор, в первом — нет.

## Откуда взяты цифры

### TikTok

Socialinsider, >6M роликов, опубликованных январь–июнь 2026.

Engagement по длине:

```text
0–15s       5.90%
15–30s      6.00%
30–60s      4.20%
60–90s      4.80%
90–120s     5.15%
120–180s    5.50%
>180s       5.90%
```

Медианные просмотры:

```text
1–15s       1,274
15–30s      1,000
30–60s      2,200
60–90s      7,200
90–120s     9,620
120–180s    11,136
>180s       10,150
```

Что из этого следует:

- по engagement лучший результат дали примерно 15–30 сек,
- по медианным просмотрам — ролики на 2–3 минуты,
- значит «все TikTok'и должны быть 10–15 секунд» — плохое универсальное допущение,
- длинный ролик оправдан только когда история реально держит внимание.

Источник: https://www.socialinsider.io/blog/how-long-are-tiktok-videos/

### Instagram Reels

Исследования Socialinsider указывают на сильный охват примерно в области 30–60 сек;
в разборе по длине самой высокой по engagement и по медианным просмотрам оказалась
корзина 45–60 сек. Отсюда стартовый приор **45–60 сек** — как приор, не как правило.

Источники:
https://www.socialinsider.io/blog/instagram-reels-length/
https://www.socialinsider.io/blog/instagram-reels-statistics/

## Почему тайминг вообще решает

Точные алгоритмы платформ закрыты, но публично заявленные сигналы ранжирования —
доля выбравших смотреть, средняя длительность просмотра, средний процент просмотра,
полные просмотры и скипы. То есть длительность влияет не сама по себе, а через
досматриваемость: ролик на 90 секунд, который бросают на двадцатой, хуже ролика на
двадцать пять секунд, который досматривают.
