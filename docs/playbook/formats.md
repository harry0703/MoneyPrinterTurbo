# Форматы

**Ниша — про что ролик. Формат — по какой сторителлинг-механике он собран.** Система
поддерживает переиспользуемые форматы, а не только ниши: формат задаёт скелет, ниша
подставляет материал.

## Реестр форматов

```text
micro_documentary
mystery_reveal
myth_busting
explainer
one_detail
hot_take
story_twist
ranking
timeline
primary_source_reveal
before_after
three_clues
comment_followup
news_context
why_it_happened
```

## Расписанные механики

### mystery_reveal

```text
"Everyone saw this goal.
But look at the player on the left."
```

Скелет:

```text
хук
→ открытая петля
→ улики / контекст
→ эскалация
→ разгадка
→ опционально второй payoff
```

### myth_busting

```text
"Everyone says X.
The actual story is Y."
```

Хорошо ложится на: историю, спортивные нарративы, техномифы, кибербез, лор игр.

### one_detail

```text
"Almost nobody noticed this detail."
```

Работает только когда визуальный материал реально способен показать эту деталь.

### explainer

```text
"Why does X happen?"
```

Рабочая лошадка для VPN/privacy-канала и evergreen-контента под привлечение.

### primary_source_reveal

Показать настоящий документ, график, карту, скриншот, архивный фрагмент, публичную
запись — и подсветить нужный кусок. Даёт ощущение подлинности выше, чем обобщённый сток.

### comment_followup

Новый ролик из реального зрительского вопроса, спора, часто повторяющегося заблуждения
или сильного комментария. Появляется только после того, как заработает ингест
комментариев.

## Стартовый микс

Для разведочного канала — рабочая гипотеза, не доказанный оптимум; это просто разумное
распределение бюджета экспериментов:

```text
30% trend-reactive
30% curiosity / surprising story
20% explanation / myth-busting
10% ranking/list
10% experimental formats
```

Как под формат пишется текст — `script.md`, чем открывается — `hooks.md`.
