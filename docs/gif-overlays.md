# GIF-вставки через KLIPY

Наложение реакционных гифок на эмоциональные пики сценария. Фича выключена по
умолчанию (`gif_enabled = false`), поведение пайплайна без неё не меняется.

Дата разработки: 2026-08-12. Ветка: `main` (не закоммичено).

---

## Зачем

Ролик, склеенный из стоковых клипов под озвучку, визуально однороден. Гифка,
попадающая в тон конкретной фразы («мем-реакция» на слова диктора), даёт точку
внимания и читается как приём, а не как случайная вставка.

Ключевое решение: **гифки ставятся не по таймеру, а по смыслу.** LLM размечает,
какие строки сценария эмоционально сильные, и придумывает под каждую запрос к
каталогу гифок.

---

## Поток данных

```
сценарий (LLM)
   ↓
озвучка (TTS) → sub_maker → тайминги фраз
   ↓
субтитры .srt  ──────────────┐
   ↓                         │
generate_gif_overlays()      │  окна ((start, end), текст)
   ↓                         │
llm.generate_gif_moments() ←─┘   один вызов LLM на ролик
   ↓  [{index: 2, query: "mind blown"}, ...]
klipy.fetch_gif()                один HTTP-запрос на пик
   ↓  скачанный mp4 в storage/cache_gifs/
video.generate_video(gif_overlays=[...])
   ↓
_build_gif_overlay_clips() → CompositeVideoClip поверх субтитров
```

## KLIPY API — что выяснили на практике

Документация `docs.klipy.com` отдаёт 403 на любой не-браузерный запрос, поэтому
схема ниже получена прямыми запросами к API.

**База:** `https://api.klipy.com/api/v1/{API_KEY}/gifs/search` — ключ в **пути**,
не в заголовке и не в query.

**Параметры:** `q`, `per_page` (8–50, деф. 24), `page`, `rating` (`g`/`pg`/`pg-13`/`r`), `locale`.

**Ответ:**
```json
{"result": true, "data": {"data": [...], "current_page": 1, "per_page": 24, "has_next": true}}
```

Каждый элемент: `id`, `slug`, `title`, `tags`, `type`, `blur_preview`, `file`.

**Форматы по типам контента:**

| Тип | Ключи `file` | Форматы | Альфа | Примечание |
|---|---|---|---|---|
| `/gifs/` | `hd`, `md`, `sm`, `xs` | mp4, webm, gif | нет | mp4 ~3 сек, 25 fps — **используем это** |
| `/stickers/` | `hd`, `md`, `sm`, `xs` (+ иногда `400`,`320`,`240`) | gif, webp, png, webm | **да** у gif/webp, **нет** у webm | часть стикеров статичные (1 кадр) |
| `/clips/` | плоский объект без размеров | mp4, gif, webp | нет | длиннее гифок |

Берём **mp4** из `/gifs/`: MoviePy декодирует его надёжно и быстро, тогда как
анимированный GIF читается медленным путём, а webm от KLIPY всё равно без альфы.

**Лимиты:** тестовый ключ — 100 запросов/час. Ответ отдаёт заголовки
`x-ratelimit-limit` и `x-ratelimit-remaining`, клиент их читает и предупреждает
при остатке ≤5. На HTTP 429 — тихая деградация (ролик собирается без гифок).

**Поиск по-русски работает**, но каталог англоязычный: запрос `деньги` вернул
релевантное, `успех` — тоже. Тем не менее LLM просим генерить **английские**
запросы (2–4 слова), они бьют точнее.

## Как выбираются моменты

Промпт в `llm.generate_gif_moments()` получает пронумерованные строки субтитров
и возвращает `[{"index": N, "query": "..."}]`. Правила в промпте:

- запрос описывает **эмоцию или визуальный гэг**, а не переводит строку
- пики распределяются по ролику, не кучкуются
- нейтральные/информационные строки пропускаются, вернуть меньше — нормально

Ответ проходит `_normalize_gif_moments()`: выкидываются дубли индексов, выходы за
диапазон, пустые запросы; результат режется до `gif_amount`. Это защита от того,
что модель сошлётся на несуществующую строку и оверлей уедет не туда.

**Проверка на реальном сценарии** (русский, 6 фраз про экономию денег) — 6 из 6
попаданий:

| Фраза | Запрос | Что нашлось |
|---|---|---|
| «не понимаешь, куда ушли деньги» | `confused math lady` | Math Confusion Meme |
| «кофе, доставка, подписки» | `drinking coffee` | Mel Gibson Sipping Espresso |
| «сумма, от которой больно» | `mind blown` | Tim And Eric Mind Blown |
| «записывай каждую трату» | `taking notes writing` | Writing Down Notes |
| «увидишь настоящие дыры» | `eyes opening realization` | Joey Tribbiani's Realization |
| «экономия начнёт работать» | `money celebration cash` | Money Cash Money |

## Тайминги

Окна берутся из субтитров: `((start, end), текст)`. Если субтитры выключены
(`subtitle_enabled = false`), SRT на диске нет — тогда `_gif_timeline()` пишет
временный `gif-timeline.srt` в каталог задачи из тех же TTS-таймингов. Так обе
ветки идут одним кодом.

Если таймингов нет вообще (нет `sub_maker`, например при кастомном аудио без
Whisper) — гифки просто не добавляются.

## Раскладка на кадре

Всё в центре смотрится мёртво, поэтому вставки разбрасываются:

| Параметр | Значение | Константа |
|---|---|---|
| Смещение вбок | 5–13% ширины кадра, стороны **чередуются** | `_GIF_SIDE_OFFSET_RANGE` |
| Наклон | 2–6°, знаком **к центру** кадра | `_GIF_TILT_RANGE` |
| Разброс по высоте | ±7% высоты кадра | `_GIF_VERTICAL_JITTER` |
| Базовая высота | 32% высоты (или 60%, если субтитры сверху) | в `_gif_overlay_placement()` |
| Ширина карточки | `gif_size`, деф. 42% ширины кадра | параметр |
| Потолок по высоте | 45% высоты кадра | в `_gif_overlay_box()` |

Смещение, высота и угол выводятся из **имени файла гифки** через
`_deterministic_unit()` (md5 → 0..1). Поэтому перегенерация той же задачи даёт ту
же раскладку — важно, чтобы повторный рендер не менял картинку молча.

Чередование сторон считается по **фактически вставленным** гифкам, а не по
индексу в списке: если одна не скачалась, две подряд на одной стороне не окажутся.

**Оформление карточки:** скруглённая маска (радиус 8% от меньшей стороны) плюс
размытая тень под ней. Кросс-фейд 0.25 сек на входе и выходе, если окно длиннее
0.5 сек. Гифка короче окна — зацикливается (`vfx.Loop`), длиннее — обрезается.

### Про поворот и маску

`vfx.Rotate` в MoviePy 2.2.1 заканчивается на `clip.transform(filter, apply_to=["mask"])`
— то есть **сам протаскивает маску** через поворот, скругление не разъезжается.
С `expand=True` размер клипа растёт (400×255 → 418×283 на 4°), и `clip.size`
обновляется корректно. Поэтому и гифка, и тень позиционируются **по центру**
(`_centered_position()`), а не по левому верхнему углу — иначе наклонённая
карточка уехала бы.

## Конфигурация

`config.toml`:
```toml
klipy_api_keys = ["..."]   # список — поддерживается ротация ключей
```

`VideoParams`:

| Поле | Деф. | Диапазон | Что делает |
|---|---|---|---|
| `gif_enabled` | `false` | bool | вкл/выкл фичу целиком |
| `gif_amount` | `5` | 1–15 | максимум гифок на ролик |
| `gif_size` | `0.42` | 0.1–0.9 | доля ширины кадра |
| `gif_rating` | `"pg"` | g/pg/pg-13/r | фильтр контента KLIPY |

В WebUI панель появляется в «Настройках видео»; без `klipy_api_keys` чекбокс
задизейблен с подсказкой.

**Расход запросов:** 1 на каждую вставку (5 гифок = 5 запросов). Скачанные файлы
кэшируются в `storage/cache_gifs/` по md5 URL, повторный рендер запросов не тратит.

## Поведение при сбоях

Ни один сбой гифок не валит задачу — ролик собирается без них:

| Ситуация | Что происходит |
|---|---|
| Нет `klipy_api_keys` | `ValueError` ловится в `generate_gif_overlays()`, лог + пустой список |
| HTTP 429 / сеть отвалилась | пустой список из `search_gifs()` |
| Ключ засветился в тексте ошибки | вырезается через `_redact_request_error()` перед логом |
| Не-https URL в ответе | вариант отбрасывается |
| Гифка не скачалась | пробуется следующая из выдачи |
| Битый файл при рендере | ловится в цикле `_build_gif_overlay_clips()`, остальные оверлеи рендерятся |
| LLM вернул мусор | `_normalize_gif_moments()` чистит, до 5 ретраев |

## Ограничения и открытые вопросы

1. **Лицензия.** Гифки KLIPY — чужой контент (мемы, кадры из фильмов, сериалов).
   Для монетизируемых роликов на YouTube/TikTok это юридически серая зона.
   Стикеры и клипы KLIPY в этом смысле чище.
2. **LLM.** Сейчас в конфиге `llm_provider = "pollinations"` с ключом `"dummy"`.
   Разметка пиков — задача на понимание тона, на слабой модели качество упадёт.
3. **Прозрачность.** У мем-гифок нет альфы, поэтому карточка в рамке. Если
   захочется вставки без рамки — это `/stickers/` с webp/gif, но каталог там
   меньше, часть стикеров статичные (надо фильтровать по числу кадров), и
   меметичность ниже.
4. **Тестовый ключ** — 100 запросов/час. Для потока роликов нужен production-ключ
   (заявка через партнёрский кабинет).
5. **Ручки раскладки** (смещение/наклон/разброс) в WebUI не выведены — правятся
   константами в `video.py`.
