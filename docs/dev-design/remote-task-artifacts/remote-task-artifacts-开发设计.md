# 开发设计文档：远程任务播放与文件查看

> **版本号**：1.0
> **编写日期**：2026-07-30
> **需求来源**：用户现场问题与增量需求
> **适用范围**：MoneyPrinterTurbo 当前 Fork / Streamlit 1.59.1 / Docker 远程部署

---

## 1. 需求概述与设计目标

### 1.1 功能清单

| 序号 | 功能 | 说明 |
|---|---|---|
| 1 | 网页内播放 | 任务管理中的“播放”不再调用服务器桌面程序，改为浏览器内预览成片 |
| 2 | 任务文件查看 | 将“打开目录”改为“任务文件”，在网页弹窗中展示可交付产物 |
| 3 | 文件下载 | 支持按需下载成片、音频、字幕、文本、JSON 和图片等安全允许的产物 |
| 4 | 远程部署清理 | 移除生成完成后自动打开服务器目录的行为 |
| 5 | 异常反馈 | 文件缺失、被删除、不支持或过大时给出明确提示，不再静默无响应 |

### 1.2 关键约束

- WebUI 运行在远程 Linux Docker 容器中，浏览器运行在用户电脑上，不能依赖 `xdg-open`、`file://` 或服务器图形桌面。
- 只能访问当前任务自己的目录，不能扩大成任意服务器文件浏览能力。
- 删除与重新生成的现有语义保持不变。
- 第一版不提供批量下载、在线编辑、目录树或全量素材浏览。

### 1.3 设计目标

- 在现有 `8501` WebUI 内完成预览和文件操作，不要求用户额外访问 API 端口。
- 不把所有任务文件预先读入内存；仅在用户打开对应弹窗后按需处理。
- 保持桌面端和移动端可用，多成片任务可选择具体成片预览。
- 存量任务无需迁移。

## 2. 系统上下文与架构影响

### 2.1 系统上下文

```text
[用户浏览器]
     |
     v
[Streamlit WebUI :8501]
     |
     +--安全扫描--> [共享卷 storage/tasks/<task_id>]
     |
     +--st.video--> 浏览器播放器
     |
     +--按需下载--> 浏览器下载
```

当前 Docker 的 WebUI 与 API 共享项目卷。首版由 Streamlit 直接读取任务产物，避免引入 `8080` 端口可达性、跨端口、反向代理和现有 API 鉴权关闭等额外条件。

### 2.2 影响范围分析

| 模块 | 影响类型 | 说明 |
|---|---|---|
| `webui/Main.py` | 修改 | 替换服务端本地打开逻辑，增加安全扫描、播放器和文件弹窗 |
| `webui/i18n/*.json` | 修改 | 增加预览、任务文件、下载及异常提示 |
| `test/services/test_webui_task_history.py` | 扩展 | 覆盖文件安全、多成片排序和产物筛选 |
| `webui/styles.css` | 按需修改 | 仅在弹窗或移动端布局确有需要时调整 |
| FastAPI Controller | 不修改 | 首版不复用现有通用性不足且未启用鉴权的下载路由 |
| 数据库/任务状态 | 不修改 | 沿用现有任务目录和状态存储 |

### 2.3 现有功能复用

- 复用 `_FINAL_VIDEO_PATTERN` 和任务目录扫描逻辑识别最终成片。
- 复用现有 `@st.dialog`、`st.session_state` 与候选任务恢复模式。
- 复用 Streamlit 原生 `st.video`、`st.download_button`，不增加前端框架。
- 复用 `utils.task_dir()`，但路径验证升级为 `realpath/resolve + commonpath`。

### 2.4 项目约束说明

仓库不存在适用于本项目的 `CLAUDE.md`/`AGENTS.md` 以及星火知识库基线设计文档；本方案以 MoneyPrinterTurbo 现有 Streamlit、任务目录与测试模式为准，不套用无关的 Java、数据库和微服务约束。

## 3. 数据模型设计

无数据库、配置格式或任务状态字段变更。文件仍由现有生成流程写入 `storage/tasks/<task_id>`，存量任务直接兼容。

## 4. 核心业务流程设计

### 4.1 网页播放

```text
点击播放
  -> session_state 记录 task_id
  -> 整页 rerun
  -> 在定时刷新区域之外打开唯一播放器弹窗
  -> 重新安全扫描该任务的 final-* 成片
  -> 单成片直接播放 / 多成片选择后播放
  -> 文件缺失时显示明确提示
```

播放器不放在任务列表的周期刷新片段内，避免任务轮询造成视频反复重载。多成片按文件名中的数字排序，而不是字符串排序。

### 4.2 任务文件查看与下载

```text
点击“任务文件”
  -> 记录 task_id 并打开文件弹窗
  -> 校验 UUID 和任务根目录
  -> 扫描安全允许的普通文件
  -> 展示相对文件名、类型、大小
  -> 用户点击某个文件下载
  -> 再次校验文件仍存在后按需读取
```

第一版允许常见交付物扩展名：视频、音频、字幕、文本、JSON 和图片。隐藏文件、符号链接、临时文件、缓存片段以及任务目录之外的路径不展示。仅显示文件名或任务内相对路径，不暴露服务器绝对路径。

### 4.3 删除与竞态

删除逻辑保持原样。若任务文件在弹窗打开后被删除，预览或下载阶段捕获文件不存在错误并提示用户刷新；不让异常中断整页。删除成功后清理与该任务相关的播放器/文件弹窗状态。

## 5. 接口设计

本次不新增或修改 HTTP API。

现有 `/stream/{file_path}` 与 `/download/{file_path}` 首版不直接复用，原因是：

- 路由鉴权依赖当前被注释；
- stream 媒体类型固定为 `video/mp4`；
- download 将所有文件标记为 `video/*`；
- 浏览器是否能访问 `8080` 取决于部署和反向代理配置。

未来若需要超大文件或多实例部署，再设计带鉴权、正确 MIME、Range 和审计能力的专用任务产物 API。

## 6. 前端交互设计

### 6.1 页面结构

```text
任务管理弹窗
  └── 任务行
       ├── 播放 -> 视频预览弹窗
       ├── 任务文件 -> 文件查看弹窗
       ├── 重新生成
       └── 删除

视频预览弹窗
  ├── 多成片选择器（存在多个成片时）
  └── 单个网页播放器

任务文件弹窗
  └── 文件行：名称 | 类型 | 大小 | 下载
```

### 6.2 状态管理

- 播放和文件查看分别使用 session state 保存候选 `task_id`。
- 打开一个弹窗时清理另一个候选，避免 Streamlit 同一次运行打开多个 dialog。
- 弹窗关闭、任务删除或文件失效后清理对应状态。
- 下载按钮使用稳定且唯一的哈希 key，并避免下载动作触发无意义的整页 rerun。

### 6.3 国际化

同步项目现有全部语言 JSON，至少新增：

- Video Preview
- Select Video
- Task Files
- File Name / File Type / File Size
- Download
- No Task Files
- File Missing / Unsupported File / File Too Large

“打开目录”改名为“任务文件”，避免继续暗示会打开用户电脑的文件管理器。

## 7. 非功能设计

### 7.1 性能

- 任务列表只判断成片/目录是否存在，不读取文件正文。
- 仅在打开弹窗时扫描单个任务目录，并限制展示文件数量。
- 下载仅在用户操作时创建；设置单文件保护上限，避免 `st.download_button` 将超大文件驻留会话内存。
- 超过上限时显示说明，后续通过专用流式 API 扩展，不在本次引入半成品接口。

### 7.2 安全

- `task_id` 强制 UUID 格式。
- 任务根目录和候选文件均解析真实路径，并用 `commonpath` 校验归属。
- 拒绝符号链接、非普通文件、隐藏文件和不允许的扩展名。
- 不接受浏览器提交的任意服务器绝对路径。
- 不展示配置、密钥、日志和临时生成文件。

### 7.3 兼容性

- Chrome、Edge、Safari 使用浏览器原生媒体能力；MP4/WebM 作为优先预览格式，MOV/MKV 即使允许下载也不承诺浏览器可直接播放。
- Docker、本机运行均使用同一套网页交互。
- 中文和空格文件名保持可展示、可下载。

### 7.4 可扩展性

安全扫描结果采用结构化文件元数据，未来可平滑替换下载实现为 FastAPI 流式接口，而不改变任务管理交互。

### 7.5 可观测性

- 预览、文件列表、下载失败记录任务 ID、任务内相对文件名和错误类型。
- 路径越界、符号链接、文件消失记录 warning。
- 日志不记录文件正文、配置内容或用户密钥。

## 8. 关键技术决策

| 决策点 | 选择 | 备选方案 | 理由 |
|---|---|---|---|
| 播放方式 | `st.video` 网页播放 | 容器安装 `xdg-open` | 服务器没有可呈现给用户的图形桌面 |
| 文件入口 | “任务文件”弹窗 | 继续“打开目录” | 浏览器不能打开服务器目录，改名更符合真实行为 |
| 首版下载链路 | Streamlit 按需下载 | 复用现有 FastAPI 下载 | 避免未鉴权、错误 MIME 和跨端口部署问题 |
| 弹窗位置 | 周期刷新区域之外 | 任务行内直接展开 | 防止播放器和弹窗被轮询反复重建 |
| 文件范围 | 交付物允许列表 | 展示整个任务目录 | 减少临时文件干扰并收紧服务器文件暴露面 |

## 10. 发现的问题与风险

| 问题/风险 | 影响 | 处理 |
|---|---|---|
| 当前播放调用容器 `xdg-open` | 日志持续报错，用户无反馈 | 删除该依赖，改网页播放 |
| 当前目录调用 `file://` | 远程浏览器不可见 | 改任务文件弹窗 |
| 生成完成后仍自动打开目录 | 远程部署残留无效行为 | 一并移除 |
| Streamlit 下载会占用会话内存 | 超大文件可能增加内存 | 按需创建并设置大小上限 |
| 文件生成/删除并发 | 弹窗快照可能过期 | 操作前复检并友好提示 |
| 现有 `/tasks` 静态挂载允许跟随符号链接且未鉴权 | 属于已有安全暴露面 | 本次新功能不使用该链路；建议后续单独安全加固 |

## 11. 验证策略

### 11.1 自动化验证

- final 多成片数字排序。
- UUID、路径穿越、同名前缀目录和符号链接逃逸。
- 隐藏文件、临时文件、目录和不允许扩展名过滤。
- 中文/空格文件名、零字节、空目录、文件消失竞态。
- 下载 key 唯一性和大小格式化。
- i18n JSON 完整性与新增键覆盖。

### 11.2 部署验收

1. 构建新的 Fork 镜像并部署到 `192.168.5.90`。
2. 点击播放，在当前浏览器弹窗中播放成片。
3. 多成片任务可选择不同成片。
4. 点击任务文件，可查看名称、类型、大小并下载允许的产物。
5. 容器无需 `xdg-open`，日志不再出现相关错误。
6. 删除、重新生成、任务筛选和生成完成展示回归通过。
7. 验证不能通过符号链接或构造路径访问其他任务及服务器文件。
